# Документация по дашбордам

Папка содержит отдельное описание каждого аналитического экрана сервиса:

- [Продажи по проектам](sales-by-project.md)
- [Анализ точек](workplace-analysis.md)
- [Карточка точки и детализация дня](workplace-point.md)
- [Анализ городов](city-analysis.md)
- [Тепловая карта](heatmap.md)
- [Отмены гигерами](worker-cancellations.md)

В каждом файле зафиксированы фактические SQL-шаблоны из `src/*Dashboard.js`, параметры фильтров, метрики и логика их расчета.

## Соглашения

Обозначения вида `<whereSql>`, `<filtered_orders>` или `<revenue_expression>` используются только для динамических фрагментов SQL, которые в коде собираются отдельно и описаны в том же документе. Параметры ClickHouse оставлены в форме `{name:Type}`, как они передаются из приложения.
